# Loft-Mafia

Telegram-бот для игры в Мафию в группах: регистрация через inline-кнопки, роли и ночные действия в ЛС, дневное обсуждение и голосование за казнь в группе.

## Запуск

Требуется Python 3.11+. Зависимости указаны в `requirements.txt`.

1. Создай бота через @BotFather.
2. Создай `.env` на основе `.env.example` и укажи `BOT_TOKEN`.
3. Создай виртуальное окружение:

```bash
python -m venv venv
```

Активация в Ubuntu:

```bash
source venv/bin/activate
```

Активация в PowerShell:

```powershell
.\venv\Scripts\Activate.ps1
```

Установи зависимости и запусти из корня проекта:

```bash
python -m pip install -r requirements.txt
python main.py
```

Для работы 24/7 нужен постоянно включённый сервер. GitHub хранит код, но не запускает бота.

## Первая партия

1. Каждый игрок отправляет боту `/start` в ЛС, чтобы получать роль и меню действий.
2. Добавь бота в группу и выдай права, необходимые для выбранных настроек модерации.
3. В группе вызови `/game`. Игроки входят через inline-кнопку под сообщением лобби.
4. Заверши регистрацию командой `/start` в группе. Управление партией проверяет необходимые права.
5. Ночные действия выбираются кнопками в ЛС. Дневные этапы сменяются по таймеру; голосование за или против казни проходит в группе.

## Команды в группе

| Команда | Назначение |
| --- | --- |
| `/game` | Открыть регистрацию новой партии |
| `/settings` | Настройки игры |
| `/leave` | Выйти из регистрации или игры |
| `/extend` | Продлить регистрацию |
| `/start` | Завершить регистрацию и начать игру |
| `/stop` | Отменить регистрацию или остановить игру |
| `/top` | Рейтинг игроков |

## Команды в ЛС

| Команда | Назначение |
| --- | --- |
| `/start` | Главное меню |
| `/roles` | Роли и описания |
| `/stats` | Статистика |
| `/top` | Рейтинг |
| `/profile` | Профиль; доступен командой, но не включён в боковое меню |

`/start` имеет разное назначение в группе и в ЛС.

Старые `/create`, `/begin`, `/kill`, `/heal`, `/check`, `/night_end`, `/vote`, `/day_end` и `/close` не используются активными обработчиками. Действия ролей выполняются через inline-кнопки.

## Состояние и обновления

По умолчанию партии, статистика и настройки сохраняются в SQLite-файле `mafia_state.db`. Другой путь задаётся переменной окружения `MAFIA_STATE_DB`.

Перед обновлением сделай резервную копию базы при остановленном боте. Сохраняй базу и `.env` между развёртываниями. Не публикуй токен.

При запуске бот восстанавливает сохранённые партии и таймеры. Поведение просроченной фазы задаётся `RESTART_EXPIRED_PHASE_POLICY`: по умолчанию `catch_up` завершает её, `restart` запускает полный таймер текущей фазы заново.

## Структура

- `main.py` — запуск и регистрация команд.
- `mafia_bot/game_domain/` — модели, роли, раздача, дневная и ночная логика.
- `mafia_bot/game.py` — совместимый публичный интерфейс доменной логики.
- `mafia_bot/handlers/` — Telegram-команды, кнопки, меню и таймеры.
- `mafia_bot/storage.py` — SQLite.
- `tests/` — regression-тесты и проверки симуляций.
- `scripts/simulate_games.py` — локальная симуляция партий.
- `mafia_bot/game_legacy.py` и `mafia_bot/handlers_legacy.py` — версии до рефакторинга; основной запуск использует новые модули.

## Тесты и симуляции

Запускай из корня проекта:

```bash
python -m unittest discover -s tests -v
```

Указывай `-s tests`: обычное обнаружение может не найти тесты в этой структуре. Тесты используют изолированное состояние и временную SQLite-базу.

Серия воспроизводимых симуляций:

```bash
python scripts/simulate_games.py --games 100 --seed 20261004 --chaos --max-rounds 60
```

Симулятор не подключается к Telegram. Он помогает искать ошибки и зависания; результаты не доказывают баланс игры с живыми участниками.
